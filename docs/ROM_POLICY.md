# ROM and Firmware Policy

PhiCade is emulator software. It is not a ROM, firmware, key, or copyrighted-game
distribution service.

Repository and release artifacts must not contain commercial ROM images, proprietary
console firmware/BIOS files, decryption keys, or links whose purpose is to obtain
unauthorized copies.

Development and automated tests should use one of:

- source-available homebrew built for testing,
- public-domain test programs,
- synthetic fixtures created by this project, or
- user-supplied software the user is legally entitled to use.

A future library scanner may index local user-selected files, but must not upload
game images by default.

This policy is a project engineering boundary, not individualized legal advice.
